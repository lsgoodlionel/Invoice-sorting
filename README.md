# 发票账本 · 个人发票报销管理工具

把“收发票、找截图、凑凭证、记进度、打包外送”变成 **拖进来 → 点一下 → 打个包**。

面向个人使用的发票与报销过程管理工具：集中存放发票和凭证，记录每笔支出从“已支出”到“已报销”的全过程，提醒还缺哪些材料，并按批次输出分类整理好的报销资料包。可以在自己电脑上运行，也可以一键部署到 Ubuntu 服务器上通过浏览器访问。

- 设计文档：[开发蓝图 v2.0](docs/个人发票报销管理工具_开发蓝图_v2.0.md)
- 接口说明：[API 契约](docs/api-contract.md)

## 功能概览

| 模块 | 能做什么 |
| --- | --- |
| **收集** | 拖入发票 PDF / XML / OFD、订单截图、支付记录；自动识别发票号码、开票日期、金额、购销双方、商品名称；自动建议分类；自动挂到之前手记的“已支出”记录；重复发票自动拦截；也可以把文件放进“收件箱”文件夹自动导入 |
| **清单** | 所有支出一张表，按状态分组显示数量与金额；按周期、日期口径、分类、经费项目、关键词筛选；显示每条记录缺几项凭证；详情抽屉里补传凭证、改分类、看时间线 |
| **凭证清单** | 按分类与金额自动列出需要的材料（如≥1000 元需支付记录、易耗品需验收单），缺什么一目了然；不需要的可标记“不需要”并写原因 |
| **状态跟踪** | 已支出 → 已开票 → 凭证齐全 → 已外发 → 已报销，按材料和批次自动推进，也可手动设置；每次变化记入时间线 |
| **批次** | 把要一起报销的记录组成批次，一键生成资料包 ZIP（汇总 Excel + 合并打印 PDF + 发票原件 + 分类支撑材料）；登记外发、到账（支持部分到账）；可重新打开 |
| **统计** | 按月 / 季度 / 年 / 自定义区间，按分类、经费项目、商家、月份交叉汇总；可切换支出、开票、外发、到账日期口径；点数字直达明细；导出 Excel |
| **提醒** | 顶部提醒条：凭证缺项、外发超期未到账、已支出久未开票、待归属附件 |
| **归档** | 文件自动按 `年/月/日期_商家_分类_金额` 整理，不打开应用也能直接浏览 |

支持识别的票据：数电发票（全电）PDF / XML、增值税电子普通/专用发票 PDF、OFD 版式发票、铁路电子客票、航空运输电子客票行程单。无法识别的文件会作为附件导入，手工填写即可。

## 快速开始（本机）

需要：[uv](https://docs.astral.sh/uv/)（自动安装 Python 3.12）、Node.js ≥ 20 与 pnpm（构建前端）。

```bash
git clone https://github.com/lsgoodlionel/Invoice-sorting.git
cd Invoice-sorting
pnpm --dir frontend install && pnpm --dir frontend build
uv run --project backend invoice-sorting
```

启动后自动打开 <http://127.0.0.1:8765>。本机模式只监听 127.0.0.1，不对局域网开放。

更新到最新版本：

```bash
git pull && pnpm --dir frontend install && pnpm --dir frontend build && uv run --project backend invoice-sorting
```

可用环境变量：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `INVOICE_SORTING_DATA_DIR` | `~/InvoiceSorting` | 数据目录 |
| `INVOICE_SORTING_HOST` | `127.0.0.1` | 监听地址 |
| `INVOICE_SORTING_PORT` | `8765` | 端口 |
| `INVOICE_SORTING_OPEN_BROWSER` | `true` | 启动时是否打开浏览器 |
| `INVOICE_SORTING_WATCH_INBOX` | `true` | 是否监听收件箱文件夹 |
| `INVOICE_SORTING_FRONTEND_DIST` | `frontend/dist` | 前端构建目录 |

## 部署到 Ubuntu 服务器

适用于 Ubuntu 22.04 / 24.04（x86_64 或 arm64）。**安装与升级是同一条命令**，重复执行即升级，数据和登录密码会保留，升级前自动备份数据库。

### 一键安装 / 升级

```bash
curl -fsSL https://raw.githubusercontent.com/lsgoodlionel/Invoice-sorting/main/deploy/install.sh | sudo bash
```

完成后终端会打印访问地址、登录用户名和**自动生成的登录密码（只显示一次，请保存）**。

### 使用域名并启用 HTTPS

域名需已解析到服务器，且 80/443 端口可访问：

```bash
curl -fsSL https://raw.githubusercontent.com/lsgoodlionel/Invoice-sorting/main/deploy/install.sh | sudo DOMAIN=invoice.example.com ENABLE_HTTPS=true EMAIL=you@example.com bash
```

### 自定义登录密码 / 重置密码

```bash
curl -fsSL https://raw.githubusercontent.com/lsgoodlionel/Invoice-sorting/main/deploy/install.sh | sudo AUTH_USER=lionel AUTH_PASSWORD='你的密码' bash
```

### 部署选项

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `DOMAIN` | `_`（任意域名 / IP） | Nginx `server_name` |
| `ENABLE_HTTPS` | `false` | `true` 时通过 Let's Encrypt 申请证书并强制跳转 HTTPS（需 `DOMAIN`、`EMAIL`） |
| `EMAIL` | — | 证书通知邮箱 |
| `AUTH_USER` | `admin` | 网页登录用户名 |
| `AUTH_PASSWORD` | 首次自动生成 | 提供则设置/重置密码 |
| `HTTP_PORT` | `80` | Nginx 监听端口 |
| `APP_PORT` | `8765` | 应用内部端口（仅本机） |
| `BRANCH` | `main` | 部署的 Git 分支 |
| `INSTALL_DIR` | `/opt/invoice-sorting` | 程序目录 |
| `DATA_DIR` | `/var/lib/invoice-sorting` | 数据目录 |

### 脚本做了什么

1. 安装 git、Nginx、sqlite3、Node.js 22、uv 等依赖
2. 创建无登录权限的系统用户 `invoice`
3. 若已有数据库，升级前备份到 `数据目录/备份/upgrade_时间.db`（保留最近 10 份）
4. 拉取代码（已安装则更新到最新提交），安装后端依赖、构建前端
5. 注册 systemd 服务 `invoice-sorting`（开机自启、异常自动重启，仅监听 127.0.0.1）
6. 配置 Nginx 反向代理 + 登录密码（HTTP Basic Auth），上传上限 100 MB
7. 防火墙 ufw 已启用时放行端口；按需申请 HTTPS 证书
8. 健康检查通过后打印访问信息

> 应用本身没有账号体系，公网部署务必保留 Nginx 登录密码，建议启用 HTTPS。

### 运维命令

```bash
sudo systemctl status invoice-sorting      # 运行状态
sudo journalctl -u invoice-sorting -f      # 实时日志
sudo systemctl restart invoice-sorting     # 重启
```

服务器上的收件箱位于 `/var/lib/invoice-sorting/收件箱/`，可以用 `scp`/`rsync` 把发票批量传进去自动导入：

```bash
scp *.pdf user@server:/tmp/ && ssh user@server 'sudo install -o invoice -g invoice -m 640 /tmp/*.pdf /var/lib/invoice-sorting/收件箱/'
```

## 使用指南

### 典型流程

```text
付款后（可选）  清单页按 N「记一笔」：日期、金额、商家 → 状态「已支出」
收到发票       收集页拖入发票 → 核对识别结果 →「全部确认」→ 自动挂到已支出记录，状态「已开票」
补齐凭证       详情抽屉里按清单拖入订单、支付记录、验收单 → 状态自动变「凭证齐全」
准备报销       批次页新建批次 →「添加记录」→「生成资料包」→ 把 ZIP 交给财务/经办人
外发后         「标记已外发」填日期、接收人、预约单号 → 状态「已外发」
钱到账后       「登记到账」（可只勾选部分记录）→ 状态「已报销」
```

### 收集：导入发票与凭证

- **拖放导入**：把发票（PDF / XML / OFD）、截图（PNG / JPG / WEBP / HEIC）一次性拖进虚线框，或点击选择文件。
- **导入确认表**：每张发票一行，显示缩略图、开票日期、销售方、金额、建议分类和匹配结果，均可直接修改：
  - 匹配列为「挂到已支出 #id」表示找到了金额相同、日期相差 7 天内的手记记录；可改为「新建」或「跳过」。
  - 黄色行是需要留意的提示，例如购方名称与设置不一致、大小写金额不一致、未识别到金额。
  - 核对无误后点 **全部确认**，这是整个导入唯一必须的人工步骤。
- **重复拦截**：同一文件或同一发票号码再次导入会提示“已存在于记录 #id”并跳过。
- **待归属附件**：非发票文件（订单截图、支付记录等）进入下方“待归属”列表，选择目标记录和材料类型即可归属；也可以直接在记录详情里上传。
- **收件箱自动导入**：把文件放进数据目录下的 `收件箱/`，几秒后自动处理——有匹配记录的挂上去，金额和日期都识别到的自动新建，其余留在待归属；无法处理的移到 `收件箱/无法处理/` 并附说明。可以把浏览器下载目录或网盘同步目录设为收件箱。

**分类是怎么自动识别的？** 按以下顺序：

1. **商品记忆**：你曾把某个商品（如“收纳盒”）改成某分类，下次同名商品直接用该分类
2. **商家记忆**：该销售方上次使用的分类
3. **发票税收分类简称**：如 `*日用杂品*` → 办公用品、`*计算机配套产品*` → 易耗品
4. **关键词**：商品名称、销售方名称中包含的关键词，取最长命中者（“打印纸”优先于“打印机”）
5. 都不命中归为“其他”

识别不准时，在导入确认表或详情里改一次分类，系统就会记住。关键词可以在「设置 → 分类」里增删。

### 清单：跟进每笔支出

- **筛选**：周期（本月 / 本季度 / 本年 / 上月 / 上季度 / 全部 / 自定义）、日期口径、分类、经费项目、搜索（商家 / 摘要 / 发票号）。筛选条件保存在网址里，可收藏。
- **状态条**：6 个状态的数量与金额，点击即按该状态筛选。
- **表格**：日期、商家·摘要、分类、金额、状态、「缺 N 项」徽标、所属批次。
- **详情抽屉**（点击任一行）：
  - 状态步进条：点击某一步手动设置状态，手动状态显示“手动”标记，可“恢复自动”
  - 基本信息：日期、金额、商家、摘要、分类、**经费项目**（下拉底部可直接新建）、付款方式、网购、备注，离开输入框自动保存
  - 凭证清单：每项显示是否已有、提示说明；缺项行内直接拖入文件上传；「不需要」可填原因，「恢复」撤销
  - 办理路径：该分类的平台操作路径与填报科目，一键复制
  - 附件：预览 PDF / 图片、修改材料类型、移回待归属、删除
  - 时间线：每次状态变化的时间、自动/手动与备注
  - 危险操作：作废（需填原因）、删除（文件移入回收站）
- **批量操作**：勾选多条后按 `B` 或点「加入批次」。
- **快捷键**：`N` 记一笔，`/` 搜索，`B` 加入批次，`Esc` 关闭抽屉。

### 批次：打包外送

- **新建批次**：填写名称（如“2026-09 科研A 第1批”）、可选经费项目。新批次为空时会直接弹出「添加记录」。
- **添加记录**：批次页「添加记录」列出所有未分批、未作废的记录（默认只显示与批次相同经费项目的记录，可切换显示全部），勾选后加入；也可以在清单页勾选后「加入批次」。
  - 记录仍有必需凭证缺项、或经费项目与批次不一致时会提示原因，确认后可「仍然加入」。
- **生成资料包**：选择分组方式后生成 ZIP，每次生成新文件、保留历史包，可随时重新下载：

  ```text
  报销资料_科研A_20260917_1402.zip
  ├── 00_报销汇总表.xlsx        汇总（序号/日期/商家/摘要/分类/金额/发票号/附件清单/缺项/备注 + 合计）与分类小计
  ├── 01_打印版_全部材料.pdf     按序号合并：发票 → 订单 → 支付记录 → 验收单 …（图片自动排成 A4）
  ├── 02_发票原件/              原始电子发票，未经修改
  │   └── 01_960.00_京东××店_26312000000123456789.pdf
  └── 03_支撑材料/              按支出分组：01_京东××店_960.00/订单明细_1.png
                                或按材料类型分组：订单明细/01_京东××店_960.00_1.png
  ```

  序号贯穿汇总表、打印 PDF 和文件名，方便财务对照。
- **标记已外发**：填写外发日期、方式、接收人、外部单号（如预约报销单号），批次内记录变为「已外发」。已外发的批次不能再增删记录。
- **登记到账**：全部或勾选部分记录到账，批次显示「部分到账」/「已到账」。
- **重新打开**：外发或到账登记有误时，重新打开回到待外发状态，记录状态按凭证清单重新计算。

### 统计

- 选择周期和日期口径（支出日期 / 开票日期 / 外发日期 / 到账日期），页面标题会注明“按××日期统计”。
- 四个数字：本期支出（不含作废）、待处理（已支出 + 已开票 + 凭证齐全）、在途（已外发未到账）、已报销（实际到账），作废金额单列。
- 交叉表：按分类 / 经费项目 / 商家 / 月份分组 × 状态，点击金额跳转到对应明细；统计数字与清单页同条件合计保持一致。
- 按月趋势柱状图；「导出 Excel」输出汇总与明细。

### 设置

| 设置项 | 说明 |
| --- | --- |
| 购方抬头与税号 | 如“华东师范大学”，导入时与发票购买方比对，不一致标黄提示 |
| 超期提醒天数 | 已外发超过该天数未到账时在提醒条显示，默认 30 天 |
| 分类 | 名称、颜色、自动识别关键词、办理路径说明；删除为归档 |
| 经费项目 | 经费号、名称、负责人；停用后不再出现在下拉中（也可在记录详情、批次中直接新建） |
| 凭证清单规则 | 分类（或通用）、材料类型、必需/建议、触发条件（金额≥、金额<、仅网购）、提示文字 |
| 备份 | 立即备份数据库；显示数据目录与收件箱路径 |

## 核心概念

### 支出记录与报销批次

- **支出记录**：一次花钱的事，例如“9 月 15 日 京东 鼠标 ×2 960 元”，包含基本信息、附件（发票、订单、支付记录、验收单等）、凭证清单、状态与时间线。
- **报销批次**：一次外送给财务/经办人的资料集合，包含若干支出记录、打包历史、外发与到账信息。

### 状态

| 状态 | 含义 | 自动进入条件 |
| --- | --- | --- |
| 已支出 | 钱花了，发票还没到 | 新建记录且没有发票 |
| 已开票 | 发票已收到并确认 | 有已确认的发票附件 |
| 凭证齐全 | 需要的材料都有了 | 凭证清单必需项全部“已有”或“不需要” |
| 已外发 | 已交给财务/经办人 | 所在批次标记已外发 |
| 已报销 | 钱已到账 | 所在批次登记该记录到账 |
| 不报销/作废 | 个人承担、重复、退货等 | 仅手动设置，需填原因 |

手动设置的状态不会被自动回退；作废或删除记录会自动移出待外发批次，已外发批次中的记录需先重新打开批次。

### 默认分类与凭证清单

| 分类 | 默认必需材料（在通用规则之外） | 办理提示 |
| --- | --- | --- |
| 办公用品 | 网购或≥500 元：订单明细 | 不在设备与实验室平台填报 |
| 易耗品 / 低值品 / 材料 | 订单明细、验收单 | 材料易耗品低值品报账，打印验收单，填“材料费” |
| 设备 | 申购单、验收单、支付记录 | 单价≥1000 元先申购，申购日期早于购买日期 |
| 软件服务 | 订单、软件服务报账单、验收单 | 填“委托其他业务费” |
| 印刷快递 | （建议）明细 | 票面已开明细可免 |
| 差旅交通 | 行程单 | 个人出行与节假日不报 |
| 餐饮会议 | （建议）工作餐单或会议材料 | 工作餐 50 元/人/餐 |
| 其他 | — | — |

通用规则：所有记录需发票；金额≥1000 元需支付记录；金额≥30000 元需合同。

> 以上规则整理自学校报销要点，**仅作提醒，以学校现行规定为准**，可在设置中按实际情况修改。

```text
├── 资料包/            生成的报销资料 ZIP
└── 备份/              数据库备份（设置页“立即备份”、服务器升级前自动备份）
```

- 原始发票文件入库后不会被修改；修改记录的日期、商家、分类或金额时，文件夹自动重命名。
- 金额以“分”为单位整数存储，不存在浮点误差。
- 完整备份 = 复制整个数据目录。本机建议放在 Time Machine / 网盘同步范围内。
- 所有数据只保存在本机或你的服务器上，不会发送到任何外部服务。

## 常见问题

**经费项目在哪里创建、怎么关联？**
三处都可以：「设置 → 经费项目」集中管理；记录详情的“经费项目”下拉底部「＋ 新建经费项目」；新建批次或批次信息中的项目下拉同样可以新建。记录关联项目后，可在清单和统计中按项目筛选汇总；批次设置项目后，「添加记录」默认只列出该项目的记录。

**发票被分到“其他”怎么办？**
在导入确认表或记录详情里改成正确的分类即可，系统会记住这个商品名称和商家，下次自动归类。也可以在「设置 → 分类」给对应分类添加关键词。

**批次打包时找不到已上传的发票？**
发票需要先加入批次：在批次页点「添加记录」勾选，或在清单页勾选记录后「加入批次」。已在其他批次、已作废的记录不会出现在可添加列表中。

**识别出来的金额或日期不对？**
导入确认表中可以直接修改；确认后在记录详情里也能修改。识别不出的发票会作为附件导入，手工填写即可。建议把识别有误的发票版式反馈到 Issues。

**可以多人使用吗？**
当前版本为个人使用设计，没有账号与权限体系。服务器部署时通过 Nginx 登录密码保护访问。

**如何迁移到另一台电脑或服务器？**
停止应用后复制整个数据目录到新位置（服务器上注意 `chown -R invoice:invoice /var/lib/invoice-sorting`），再启动即可。
