# 清单、办公用品分类、批次汇总与多维统计升级设计

## 目标

1. 清单同时展示发票开票日期、业务发生日期、凭证填报日期，并支持按任一日期筛选和排序。
2. 清单支持状态筛选与排序；默认隐藏“已外发”“已报销”，用户可切换查看范围。
3. 清单支持按日期、摘要、分类、金额、状态排序，并允许选择显示列。
4. 清单和所有 Excel 汇总统一提供名称、单价、数量、总价、发票号。
5. 依据 `24641.jpg` 补齐办公用品七类关键词，并将“是否需要设备与实验室管理平台申请”结构化到分类、清单筛选、批次汇总和统计。
6. 批次资料包除总汇总和分类小计外，为每个分类生成明细汇总 Sheet，显示记录数、材料数和金额合计。
7. 统计支持行维度 × 列维度交叉汇总，至少覆盖分类、月份、批次、状态，并可从分组名称、数字和合计穿透清单。

## 数据模型

- `Category.requires_lab_platform: bool`：是否需要在设备与实验室管理平台填写申请。默认“材料、易耗品、低值品”为是，其余为否，可在分类设置中修改。
- `Expense.item_name: str`：名称；优先由识别结果回填，允许手工修改。
- `Expense.unit_price_cents: int | None`：单价。
- `Expense.quantity: int | None`：数量。
- `Expense.amount_cents` 继续作为总价，避免破坏既有金额、状态和到账逻辑。
- 三个日期不重复落库：开票日期取关联发票最早 `InvoiceData.issued_on`；业务日期为 `Expense.spent_on`；填报日期为 `Expense.created_at` 的上海日期。

## 查询与排序

- 日期口径新增 `created`（凭证填报日期），保留 `spent/invoiced/sent/received` 兼容既有链接与统计。
- 支出列表新增 `sort_by`、`sort_order` 和 `requires_lab_platform`；允许排序字段：日期、摘要、分类、金额、状态。
- 默认状态范围由前端设为 `spent,invoiced,complete`；用户选择“全部”或指定状态后写入 URL，统计穿透链接不受默认隐藏影响。
- 列显示偏好保存在浏览器本地，URL 仅保存业务筛选和排序，避免链接过长。

## 导出

- 批次总汇总、分类明细、统计明细统一包含：名称、单价、数量、总价、发票号。
- 批次“分类小计”包含清单数、材料数、金额；每个分类 Sheet 底部显示同样三项合计。
- 材料数按记录附件数量累计，清单数按支出记录数累计。
- 分类 Sheet 名进行 Excel 非法字符清理和 31 字符截断，并保证唯一。

## 多维统计

- 行维度 `group_by` 与列维度 `cross_by` 分开；列维度支持状态、分类、月份、批次。
- API 返回 `columns` 和每行 `cells`，每个单元格含数量与金额；保留原 `by_status` 字段，兼容旧客户端。
- 总计卡片、行名称、单元格和行合计均生成清单链接；链接携带日期口径、区间、状态、分类、批次等筛选。

## 兼容与迁移

- 使用现有 SQLite 轻量补列机制；新增列均有默认值或允许 NULL。
- 分类平台标记通过独立版本设置幂等回填，只更新系统默认分类，不覆盖用户新增分类。
- 旧记录名称为空时，显示/导出依次回退到摘要、发票商品摘要、商家；单价和数量未知时留空，不伪造数据。
