# 注册申请与推荐 · 设计

编制日期：2026年9月21日　　适用：多账套（SaaS）部署。单账套部署不出现以下任何入口。

## 1 目标

1. **申请推荐码**：没有推荐码的访客在登录页点「申请使用」，填写身份、邮箱与需求，提交到平台运营后台；平台管理员批准或否决，结果以邮件通知申请人。批准即为其**新开一个独立账套**。
2. **推荐分享**：已登录的普通用户可以分享自己的推荐链接，系统自动为其生成推荐码；被推荐人注册后同样获得独立账套。平台后台**实名记录**推荐关系。
3. 推荐注册是否需要平台审批，由运营后台的**开关**决定。

## 2 概念

| 名称 | 说明 |
| --- | --- |
| **注册申请** | 访客提交的资料，状态：待审批 → 已批准 / 已否决；批准后发放**注册码** |
| **注册码** | 一次性、绑定申请邮箱、默认 7 天有效；凭它完成注册并开通账套 |
| **推荐码** | 每个用户一个、长期有效、可重置；用于生成推荐链接 `/apply?ref=推荐码` |
| **推荐记录** | 谁推荐了谁：推荐人账号与姓名、被推荐人邮箱与账套、时间、结果 |

现有的**邀请码**（账套管理员邀请他人加入**自己的账套**）保持不变，与本设计互不影响。

## 3 流程

### 3.1 申请（无推荐）

1. 登录页「还没有账号？申请使用」→ 申请表：姓名、邮箱、单位或身份、使用需求简介（必填），期望账本名称（选填）。
2. 提交后显示申请编号，提示"审批结果会发到你的邮箱"。
3. 平台后台「申请」页签：列表、详情、**批准**（可修改账套标识与名称、选择套餐与到期日）或**否决**（填写原因，可选）。
4. 批准：生成注册码，发邮件（含注册链接 `/register?code=…` 与有效期）；否决：发邮件告知结果与原因。

### 3.2 推荐

1. 用户在「设置 → 推荐好友」看到自己的推荐链接（首次打开自动生成推荐码），可复制、可重置（旧链接立即失效）。
2. 被推荐人打开链接进入申请表，推荐人已预填且不可修改。
3. 平台开关：
   - **需审批**（默认）：走 3.1 的审批流程，后台显示"由 某某 推荐"。
   - **直接注册**：填完资料立即发放注册码并发信（仍要验证邮箱），每个推荐人每月名额有上限（默认 5，平台可调），超出后自动转为需审批。

### 3.3 完成注册

打开注册链接 → 注册页显示邮箱（只读）→ 设置用户名与密码 → 创建账号、开通独立账套（本人为管理员，默认免费套餐）→ 直接登录进入。注册码随即作废。

## 4 邮件

- **网页配置为主**：平台管理员在「平台 → 邮件」页签填写 SMTP 服务器、端口、加密方式（`ssl`/`starttls`/`none`）、账号、密码、发件人与站点地址（生成链接用），保存即生效；同页可「测试连接」（只登录不发信）与「发送测试邮件」（每位平台管理员每分钟 3 次），并记录最近一次验证结果、时间与操作人。配置存控制库单行表 `mail_settings`，同时记录最后修改人与时间。
- **环境变量优先**：`INVOICE_SORTING_SMTP_HOST` 与 `SMTP_FROM` 都配置时整体以环境变量（`SMTP_PORT`、`SMTP_USER`、`SMTP_PASSWORD`、`SMTP_TLS`、`PUBLIC_BASE_URL`）为准，网页只读显示「由服务器环境变量配置」，保存接口 409。发信、测试与「是否已配置邮件」统一经 `mailer/resolve.py` 按「环境变量 → 网页配置 → 未配置」解析；网页配置未填站点地址时退回 `PUBLIC_BASE_URL`。
- **加密存储**：网页填写的密码用 Fernet 加密入库；密钥取环境变量 `INVOICE_SORTING_SECRET_KEY`，否则首次需要时在数据目录生成 `secret.key`（0600）。密钥不入库、不随账套搬迁包与诊断包导出；任何接口不返回密码或密文。密钥丢失或更换导致解密失败时提示「请重新填写 SMTP 密码」（发信记为失败），不会 500。
- 凭证不进日志、错误信息与诊断包；错误说明按异常类型给固定中文，不拼接服务器原文。连接超时 10 秒。
- **未配置 SMTP 时不发信**：批准或否决后，后台直接显示注册链接与一段可复制的通知文字，由管理员自行转告。
- 发送失败不影响审批结果：记录失败原因，后台可「重新发送」。
- 邮件只含结果、注册链接与有效期，**不含密码或任何账本数据**。

## 5 防滥用

- 申请接口公开，但按 IP 限流（默认每小时 5 次）；同一邮箱有待审批申请时不能重复提交。
- 表单带隐藏诱饵字段，填了即静默丢弃（不提示机器人）。
- 注册码一次性、绑定邮箱、有效期 7 天；注册时邮箱不可修改，确保收信人本人注册。
- 推荐直接注册模式下，推荐人每月名额有上限，超出自动转审批。
- 推荐码可随时重置；平台可停用某人的推荐资格。

## 6 隐私与记录

- 申请资料（姓名、邮箱、身份、需求）与推荐记录**只有平台管理员可见**，账套管理员与普通用户看不到别人的申请。
- 推荐人只能看到自己推荐了几人、各自状态（已注册/待审批），看不到被推荐人的需求等资料。
- 否决的申请保留 180 天后自动删除个人资料（保留统计计数）。
- 所有审批操作记录操作人与时间。

## 7 接口草案

| 方法 | 路径 | 权限 |
| --- | --- | --- |
| POST | `/api/signup/applications` | 公开（限流） |
| GET | `/api/signup/referral/{code}` | 公开：校验推荐码有效，返回推荐人显示名 |
| GET/POST | `/api/signup/register?code=` / `/api/signup/register` | 公开：校验注册码 / 完成注册 |
| GET/POST | `/api/referrals/me`、`/api/referrals/me/reset` | 登录用户 |
| GET | `/api/platform/applications` | 平台管理员 |
| POST | `/api/platform/applications/{id}/approve`、`/reject`、`/resend` | 平台管理员 |
| GET | `/api/platform/referrals` | 平台管理员 |
| GET/PATCH | `/api/platform/signup-settings` | 平台管理员（审批开关、每月名额、注册码有效期） |
| GET/PATCH | `/api/platform/mail-settings` | 平台管理员（邮件配置；环境变量配置时 PATCH 409） |
| POST | `/api/platform/mail-settings/test-connection`、`/test-email` | 平台管理员（用已保存并生效的配置验证） |
