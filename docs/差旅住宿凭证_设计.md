# 差旅住宿凭证 · 设计

编制日期：2026年9月18日

## 1 目标

一笔住宿差旅报销的完整凭证 = **酒店发票 + 酒店订单 + 往来交通凭证**（往返酒店所在地与本地的火车、飞机、汽车、轮船票或行程单）。交通票金额**并入同一笔差旅报销**。凭证可以一次上传，也可以分多次、由不同用户上传补全；在收集页内自动识别、归组、匹配已有记录。

## 2 识别

### 2.1 酒店订单（新识别器 `hotel_booking`）

平台：携程 / Trip.com、美团、飞猪、同程、艺龙、去哪儿、Booking.com、Agoda、Expedia、华住会、锦江、亚朵等；PDF 文本层或截图 OCR。

样例（携程 `BookingConfirmation.pdf`，文本层）：

```
订单确认单 … 请查收您的行程确认单。房费预付到携程，酒店不提供水单。
订单号 1132548283006095 订单金额: ¥720.00 (个人支付)
苏州 - 苏州园区阳澄湖泰康万豪酒店
入住日期 2026年8月15日 15:00后 离店日期 2026年8月16日 12:00前
房型 经典阳台大床房 房间数量 1
入住人 李欣
Copyright © 1999-2026, ctrip.com
```

输出：`doc_type=order`、`recognizer=hotel_booking`、订单号、金额（CNY）、`occurred_on`=离店日期、`merchant`=酒店名、`item_name`=“酒店名 入住–离店 N晚 M间”，以及 `details`：

| 键 | 含义 | 例 |
| --- | --- | --- |
| city | 酒店所在城市 | 苏州 |
| hotel | 酒店名 | 苏州园区阳澄湖泰康万豪酒店 |
| check_in / check_out | 入住 / 离店日期 YYYY-MM-DD | 2026-08-15 / 2026-08-16 |
| nights / rooms | 晚数 / 房间数 | 1 / 1 |
| guest | 入住人 | 李欣 |
| platform | 预订平台 | 携程 |

### 2.2 交通凭证

| 来源 | 类型 | details |
| --- | --- | --- |
| 铁路电子客票、航空运输电子客票行程单（发票解析器，已有 `travel`） | 发票（计入金额） | date、from、to、vehicle（train/flight）、number（车次/航班）、passenger |
| 12306 / 航司 / 携程等的车票、机票订单截图或 PDF（新识别器 `transport_booking`） | 往来交通凭证（`transport`，不计金额） | 同上，另含 vehicle bus/ship |
| 汽车票、船票发票 | 发票 | 能识别则填 details |

`InvoiceData.details` 保存发票解析出的 travel 信息（旧库补列后可能为 NULL，按空处理）。

## 3 归组（本次上传内）

在现有 L1–L4 之外增加：

- **L6 酒店发票 ↔ 酒店订单**：订单号一致（已有 L1）；或 人民币金额相同 + 酒店名与销售方有 ≥2 字公共子串 + 开票日期在入住日期至离店后 30 天内。依据“酒店发票与订单一致”。
- **L7 住宿 ↔ 交通**：交通 date 在 [入住−1 天, 离店+1 天] 内，且 from/to 任一包含酒店城市（或住宿组的城市：订单 city，或酒店发票销售方名称中的城市）。依据“往返酒店所在地的交通凭证”。
- **多发票组**：一组可以包含“一张住宿发票 + 若干交通票发票”（住宿发票：税收分类/商品/销售方含 住宿、酒店、宾馆 等；交通票发票：details.vehicle 非空或税收分类为 旅客运输服务/客运 等）。其他情况仍每组最多一张发票。

组摘要：金额 = 组内全部发票价税合计之和；商家 = 酒店名；摘要 = “酒店名 N晚 + 交通 K 张”；分类 = 差旅交通；日期 = 入住日期（无订单时取住宿发票开票日期）。

## 4 匹配已有记录（分次上传）

- 订单号一致 → 强匹配（已有 M1）。
- 住宿记录（记录内有酒店订单或住宿发票）与新上传交通凭证：日期在入住前后 1 天内且城市匹配 → +60 分，依据“往返 苏州 的交通凭证（入住 08-15、离店 08-16）”。
- 住宿发票 ↔ 已有“只有订单”的记录：金额相同 + 酒店名匹配 + 日期窗口 → +70 分。

## 5 金额并入

- 新建：金额 = 组内发票合计。
- 挂到已有记录（attach、批量归属、清单行拖放）一张交通票**发票**：若记录当前金额等于挂之前该记录发票合计（未手动改过），自动更新为新的发票合计，时间线记“并入交通票 ¥xx”；手动改过金额则不动，时间线提示“金额未自动调整”。

## 6 凭证清单（规则版本 6）

- 差旅交通 + 住宿关键词：订单明细（酒店订单，已有 v5）+ **往来交通凭证（必需）**：“往返酒店所在地与本地的火车/飞机/汽车/轮船票或行程单”。
- “往来交通凭证”满足条件：记录中有 `transport` 类型附件，**或**有 details.vehicle 非空的发票（交通票发票）。
- 只有订单（无发票）时照常建记录：发票、往来交通凭证显示缺失。
